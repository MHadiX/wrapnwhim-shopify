# WrapnWhim 1.1.0 layout refresh

This revision retains WrapnWhim’s custom visual identity. The user-supplied Horizon theme was used only to compare Shopify architecture, not as a design base.

- Centered header and balanced editorial hero with a dedicated mobile composition.
- Smaller photographic category cards with readable labels; six initial cards and accessible expansion for the remaining six.
- Scrollable occasion cards retaining all eleven configurable destinations.
- Shared product cards with configurable square/portrait media, full-product/fill fit, readable two-line titles and prices, visible aligned purchase actions, quick view and wishlist.
- Direct quick add for default-variant products using Shopify cart API, minimum quantities and explicit server errors. Variant products use a real option form; personalized products open the full customization page.
- Collection/search filter sidebar on desktop and expandable mobile panel; native filtering, sorting and pagination retained.
- Product price above options, reserved gallery space, first-image priority, lazy remaining media, and a compact personalization form layout.
- Unconfigured featured-product/review sections avoid empty storefront bands; setup remains visible in the theme editor.
- Typography, gutters, section spacing, cards, cart, builder and supplementary layouts share the refreshed design system.

See QA.md for current local evidence and pending Shopify-store checks. Upload WrapnWhim-1.1.0.zip as an unpublished theme, configure actual collections/products and preview before publication. The previous 1.0.0 ZIP remains available separately; merchant content from the reference export is not migrated.
